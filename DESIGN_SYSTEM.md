# Design System — Ford Raptor Compare

## Direção visual

A interface usa uma linguagem corporativa clean, inspirada em dashboards automotivos: navy para navegação, superfícies brancas, cinzas suaves, azul como ação principal e cores semânticas apenas para estados.

## Componentes

- Cards: `14–16px` de raio, borda de 1px, sombra leve.
- Botões: altura mínima de `40–52px`, foco visual azul.
- Cabeçalhos: navy/preto com títulos brancos.
- Inputs: fundo `surfaceSoft`, borda `borderStrong`.
- Status: verde/âmbar/vermelho reservados para estado.
